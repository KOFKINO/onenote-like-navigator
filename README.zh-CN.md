# OneNote Like Navigator

[English](README.md) · [安装](#安装) · [版本与更新记录](https://github.com/KOFKINO/onenote-like-navigator/releases) · [反馈问题](https://github.com/KOFKINO/onenote-like-navigator/issues)

**这是一个 Obsidian 插件：以 OneNote 风格浏览现有文件夹和笔记，直接管理真实文件。**

切换笔记本时不再平铺整个笔记库的目录树。默认进入文件夹后，左栏只显示下一级子目录，右栏显示直属笔记。长名称自动换行，目录再深也不会增加横向列数。

**当前界面语言为简体中文。** 英文文档中的翻译仅供理解，插件尚未提供英文界面。

## 功能

- 一级文件夹自动成为笔记本，无须逐个配置。
- 默认逐层浏览；可开启完整目录树，也可聚焦某个文件夹。
- 直接新建、重命名、移动、排序和删除真实文件。
- 默认在新标签页打开笔记并切换到前台，也可复用当前标签页。
- 分别记住各笔记本的浏览状态；在 Obsidian 内调整文件夹后，导航随之更新。

## 安装

需要 **Obsidian 1.7.2 或更新版本**。移动端及触控操作尚未完成实机验证。

### 社区插件市场

打开[官方目录页面](https://community.obsidian.md/plugins/onenote-like-navigator)，选择 **Add to Obsidian**。也可以在 Obsidian 的 **设置 → 第三方插件 → 浏览** 中搜索 **OneNote Like Navigator**，安装并启用。

新版本处理期间，市场与 GitHub 的版本可能不同。安装前查看版本号；需要 GitHub 较新版本时可使用下面的手动方式。

### 手动安装或更新

1. 从[最新 Release](https://github.com/KOFKINO/onenote-like-navigator/releases/latest) 下载 `main.js`、`manifest.json`、`styles.css`，不要下载源码 ZIP 作为安装包。
2. 创建 `<笔记库>/.obsidian/plugins/onenote-like-navigator/`，将三个文件直接放入该目录。
3. 重新加载 Obsidian，在 **设置 → 第三方插件** 中启用 **OneNote Like Navigator**。

手动更新时，先禁用插件，仅替换上述三个文件，再重新加载并启用。保留 `data.json`，以保留设置和排序。使用 Release 安装不需要编译、账号或订阅。

## 快速开始

1. 点击左侧功能区的方形笔记本图标，或在命令面板运行 **OneNote Like Navigator: 打开笔记本导航**。
2. 点击顶部笔记本名称切换笔记本。
3. 点击文件夹，左栏展示下一级子目录，右栏展示直属笔记；点击笔记打开，点击返回箭头回到上级。

进入文件夹时会默认选中 **本层页面**。它是直属笔记列表的入口，不会额外创建 Markdown 文件，也不会自动打开第一篇笔记。

## 命令与界面文字

命令面板中的命令带有 **OneNote Like Navigator:** 前缀。插件没有预设全局快捷键，可在 **设置 → 快捷键** 中自行绑定。

| 文字 | 用途 | 位置 |
| --- | --- | --- |
| 打开笔记本导航 | 打开导航侧栏 | 命令面板 |
| 切换笔记本 | 选择其他笔记本 | 命令面板 |
| 定位当前笔记 | 在导航中定位当前笔记 | 命令面板 |
| 在当前分区新建笔记 | 在当前分区创建笔记 | 命令面板 |
| 本层页面 | 查看当前文件夹的直属笔记 | 导航界面 |
| 聚焦此文件夹 | 将导航范围聚焦到该文件夹 | 文件夹右键菜单 |
| 退出聚焦 | 恢复聚焦前的导航状态 | 聚焦后的导航界面 |
| 移动到… | 选择目标文件夹 | 右键菜单 |
| 移入回收站… | 确认后删除到回收站 | 右键菜单 |

## 设置

| 设置 | 默认值 | 效果 |
| --- | --- | --- |
| 显示完整目录树 | 关闭 | 默认仅显示下一级子目录；开启后展示可展开的嵌套目录树。 |
| 在新标签页打开并置于前台 | 开启 | 新建标签页并立即激活；关闭后复用当前标签页。新标签页不会改变已有标签的顺序，也不会被移动到最左侧。 |
| 启动时打开笔记本导航 | 开启 | 启动后在左侧栏显示导航。 |
| 显示附件 | 关闭 | 默认仅显示 Markdown 笔记；开启后包含其他文件。 |
| 恢复隐藏的笔记本入口 | 操作按钮 | 点击「显示全部」恢复被隐藏的笔记本入口。 |

完整目录树模式下，点击文件夹会选中并展开，点击三角按钮仅展开或折叠。右键选择 **聚焦此文件夹** 可缩小导航范围，点击 **退出聚焦** 恢复之前的导航状态。隐藏笔记本入口不会删除对应文件夹。

## 文件操作与快捷键

下表中的快捷键仅在导航中的文件夹或笔记按钮获得键盘焦点时生效，不适用于编辑器或搜索框内输入时。

| 操作 | 方法 |
| --- | --- |
| 新建 | 对应的 `+` 按钮或右键菜单。 |
| 重命名 | 右键菜单或 `F2`。 |
| 同级排序 | 拖到条目上、下边缘，或按 `Alt + ↑/↓`。 |
| 移入文件夹 | 拖到目标文件夹条目中央。 |
| 移回上一级 | 拖到顶部的返回箭头按钮。 |
| 跨笔记本移动 | 右键 → 移动到…，搜索并选择目标文件夹。 |
| 删除 | 右键菜单或 `Delete`，确认后移入笔记库的 `.trash`；删除文件夹会包含其内部内容。 |
| 列表内移动焦点 | `↑/↓` 选择上、下一项；`Home/End` 跳到首、末项。 |
| 进入或返回文件夹 | `→` 进入或选中文件夹；`←` 折叠已展开的树节点，否则选中父文件夹。 |

排序只影响本插件中的显示顺序，不修改文件名，也不改变原生文件管理器的排序。

## 同类插件对比

这里比较导航方式，不做完整功能排名。以下事实依据链接中的项目文档，核对日期为 2026-11-13。

| 插件 | 已确认的导航方式 |
| --- | --- |
| **OneNote Like Navigator** | 一级文件夹作为笔记本；默认左侧显示下一级子目录、右侧显示直属笔记。直接管理真实文件，无须逐个配置笔记本。 |
| [Notebook Navigator](https://github.com/johansan/notebook-navigator) | 双栏浏览，包含文件夹、标签、属性、预览、键盘导航与手动排序。 |
| [Fluent OneNote](https://community.obsidian.md/plugins/fluent-onenote) | 弹窗或侧栏中的笔记本、分区、页面导航；支持配置根目录、文件夹笔记子页面，以及拖动排序和移动。 |

真实文件夹和文件管理并非本插件独有。本插件重点是跟随现有文件夹结构、默认仅显示下一级的紧凑浏览方式。

## 隐私与数据

- 本插件本地运行，不发起网络请求，不含统计、广告、账号或付费功能。
- 通过 Obsidian API 管理当前笔记库内的文件。
- 排序与浏览偏好保存到插件的 `data.json`，不写入笔记正文或属性。
- 删除、链接更新、配置与卸载行为详见 [FAQ 中文部分](FAQ.md#简体中文)。

## 限制

- 不支持虚拟父子页面、多选批量管理或 OneNote 文件导入、转换。
- Obsidian 关闭期间从外部重命名文件，可能导致旧排序或浏览状态关联丢失。
- 侧栏宽度小于 280 px 时，双栏改为上下排列；完整目录树的深层缩进有上限，并以层级数字标记。
- 已验证桌面逻辑及浏览器渲染的交互，移动端和触控尚未完成实机测试。
- 当前只有中文界面；提供英文文档不代表已实现英文界面。

## 开发与贡献

需要 **Node.js 20+ 和 npm**。克隆仓库后，在仓库根目录运行：

```sh
npm ci
npm run build
npm test
```

`npm ci` 根据已提交的锁文件完成可复现安装；主动调整依赖时使用 `npm install`，并提交更新后的锁文件。当前项目没有第三方包依赖。

源码在 `src/`，构建生成根目录的 `main.js`。测试使用内存中的 Obsidian 模拟适配器，不访问真实笔记库。CI 检查测试结果及提交的 `main.js` 是否与构建结果一致。分支、提交、PR 和翻译同步要求见 [贡献指南](CONTRIBUTING.md#简体中文)。
